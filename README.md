# Demostración de Compiladores (LL(1) / CFG) vs. Procesamiento de Lenguaje Natural (NLP)

Este proyecto contrasta el diseño de un analizador sintáctico descendente recursivo **LL(1)** para un lenguaje formal frente a las limitaciones matemáticas y estructurales de las **Gramáticas Libres de Contexto (CFG)** cuando se aplican al idioma español.

## Requisitos del Sistema

- Python 3.9 o superior.
- Librerías de NLP: `spacy` y `nltk`.
